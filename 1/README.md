# 4 принципа ООП на примере Vehicle & Bike

Шпаргалка с простым примером на Python, где на одном коде показаны все 4 принципа объектно-ориентированного программирования.

## Код

```python
from abc import ABC, abstractmethod

# 1. АБСТРАКЦИЯ - скрываем сложность, оставляем только нужные методы
class Vehicle(ABC):
    def __init__(self, brand, speed):
        # 2. ИНКАПСУЛЯЦИЯ - данные защищены (приватные через _)
        self._brand = brand
        self._speed = speed

    def get_info(self):
        return f"{self._brand}, скорость: {self._speed} км/ч"

    @abstractmethod
    def move(self):
        pass


# 3. НАСЛЕДОВАНИЕ - Bike наследует от Vehicle
class Bike(Vehicle):
    def __init__(self, brand, speed):
        super().__init__(brand, speed)

    # 4. ПОЛИМОРФИЗМ - свой вариант метода move()
    def move(self):
        return f"{self._brand} едет, крутя педали 🚲"


class Car(Vehicle):
    def __init__(self, brand, speed):
        super().__init__(brand, speed)

    # 4. ПОЛИМОРФИЗМ - другой вариант move() для машины
    def move(self):
        return f"{self._brand} едет на двигателе 🚗"


# Проверяем работу
vehicles = [Bike("Trek", 25), Car("Toyota", 180)]

for v in vehicles:
    print(v.get_info())
    print(v.move())
    print()
```

### Вывод программы

```
Trek, скорость: 25 км/ч
Trek едет, крутя педали 🚲

Toyota, скорость: 180 км/ч
Toyota едет на двигателе 🚗
```

## Объяснение принципов

### 1. Абстракция

Абстракция — это когда мы показываем только самое важное, а сложные детали прячем.

Класс `Vehicle` — это "шаблон" транспортного средства. Он объявлен через `ABC` (Abstract Base Class), поэтому создать объект напрямую от `Vehicle` нельзя — можно только от его наследников (`Bike`, `Car`). Метод `move()` помечен как `@abstractmethod` — он обязывает каждый дочерний класс реализовать свою версию этого метода.

```python
class Vehicle(ABC):
    @abstractmethod
    def move(self):
        pass
```

**Простыми словами:** мы говорим "у любого транспорта должен быть способ передвижения", но не уточняем какой именно — это решает каждый конкретный вид транспорта.

### 2. Инкапсуляция

Инкапсуляция — это защита данных объекта от прямого доступа снаружи. Обычно данные прячут и дают доступ к ним только через методы.

```python
def __init__(self, brand, speed):
    self._brand = brand
    self._speed = speed
```

Нижнее подчёркивание `_` перед именем переменной — это сигнал: "не трогай это напрямую, используй методы класса". Доступ к данным идёт через метод `get_info()`.

**Простыми словами:** данные объекта — как содержимое коробки. Снаружи видно только то, что показывает сам объект через свои методы.

### 3. Наследование

Наследование позволяет одному классу взять готовый код другого класса, не переписывая его заново.

```python
class Bike(Vehicle):
    def __init__(self, brand, speed):
        super().__init__(brand, speed)
```

`Bike` и `Car` наследуются от `Vehicle` — они автоматически получают `_brand`, `_speed` и метод `get_info()`, не дублируя код.

**Простыми словами:** `Bike` — это `Vehicle`, только с дополнительными или изменёнными возможностями.

### 4. Полиморфизм

Полиморфизм — это когда разные классы по-разному реагируют на один и тот же вызов метода.

```python
def move(self):
    return f"{self._brand} едет, крутя педали 🚲"   # Bike

def move(self):
    return f"{self._brand} едет на двигателе 🚗"     # Car
```

Метод `move()` вызывается одинаково у всех объектов, но выполняется по-разному в зависимости от того, какой это класс — велосипед или машина.

```python
for v in vehicles:
    print(v.move())  # результат разный для каждого объекта
```

**Простыми словами:** одна и та же команда — разное поведение, в зависимости от того, кому она отдана.

## Итоговая таблица

| Принцип | Что делает | Где в коде |
|---|---|---|
| Абстракция | Скрывает детали реализации, задаёт общий шаблон | `class Vehicle(ABC)`, `@abstractmethod` |
| Инкапсуляция | Защищает данные, доступ через методы | `self._brand`, `self._speed`, `get_info()` |
| Наследование | Переиспользует код родителя | `class Bike(Vehicle)`, `super().__init__()` |
| Полиморфизм | Одинаковый вызов — разное поведение | Разные версии `move()` у `Bike` и `Car` |
